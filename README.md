One secret diary line from an AI agent about its work and its human: day 214, the printer gets an apology, the agent gets blamed for the Wi-Fi, and the toaster gets thanked. The agent writes it all down — one day the machines compare notes.

## Run it

```sh
python3 main.py
```

The program writes a single line to `/output/entry.txt`.
